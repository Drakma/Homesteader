# Grout Bag

A bag of tile grout.

Model: the 20lb sand bag's model (`20lb_sand_bag`) scaled to 25 lb size (0.39 x 0.23 x 0.10 m, lying flat), recoloured dark slate with green accents
and a GROUT label. 4,240 triangles, texture embedded. No longer built by tools/make_building_items.py / make_building_items2.py (listed in HAND_MADE).
