# Mortar Mix Bag

A 60 lb bag of dry mortar mix for laying brick, block and stone.

Model: the 20lb sand bag's model (`20lb_sand_bag`) scaled to 60 lb size (0.54 x 0.31 x 0.14 m, lying flat), recoloured off-white with blue accents
and a MORTAR MIX label. 4,240 triangles, texture embedded. No longer built by tools/make_building_items.py (listed in its HAND_MADE set).
