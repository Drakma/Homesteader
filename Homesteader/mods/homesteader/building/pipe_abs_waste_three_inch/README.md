# 3" Black Waste Pipe

**Item ID:** `pipe_abs_waste_three_inch`  
**Category:** `building`  
**Icon:** ![3" Black Waste Pipe](pipe_abs_waste_three_inch.png)

A 3 m length of black ABS waste pipe for a building's drain line. With a pipe wrench in hand, right click a building's waste outlet and then a macerator pump or a septic tank to lay it (and on from the tank to a distribution box and its leach fields). Outside it runs underground.

Procedural model (tools/make_septic.py). See docs/SEPTIC.md.
