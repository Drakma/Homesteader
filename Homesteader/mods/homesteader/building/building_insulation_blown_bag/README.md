# Blown Insulation Bag

A bag of loose-fill attic insulation.

Model: a compressed, plastic-wrapped bale lying flat (0.75 x 0.42 x 0.26 m), pink wrap with a white band and a BLOWN INSULATION label. 4,256 triangles,
texture embedded. Source: Gemini reference image, Meshy image-to-3D (meshy-t2, smart-topology, textured). No longer built by
tools/make_building_items.py / make_building_items2.py (listed in HAND_MADE).
