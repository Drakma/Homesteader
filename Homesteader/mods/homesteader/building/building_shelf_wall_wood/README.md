# Wall Shelf

A pine board on two black steel angle brackets. Mount it on a wall, then stand things on it: left click with the item in hand, right click the item to take it back.

Procedural model (tools/make_shelves.py), 252 triangles, 0.90 x 0.25 x 0.23 m. A wall item (`attach_surface: wall`) that is a shelf (`shelf: true`): things stand on its top face. See docs/ATTACHED_ITEMS.md.
