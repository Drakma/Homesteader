# Packed Dirt Path Kit (`path_dirt`)

![Packed Dirt Path Kit Icon](path_dirt.png)

## Overview
- **Category**: `building`
- **Item Identifier**: `path_dirt`
- **Kind**: path (1.2 m wide, dirt surface)
- **Lays**: 3.0 m of route per item
- **Base Economic Value**: $2.0

## Description
A bag of packed earth and edging for a smooth footpath.

Hold it and click to lay control points; the route is a smooth curve through them (docs/PATHS.md).
