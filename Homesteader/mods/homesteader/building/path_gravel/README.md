# Gravel Path Kit (`path_gravel`)

![Gravel Path Kit Icon](path_gravel.png)

## Overview
- **Category**: `building`
- **Item Identifier**: `path_gravel`
- **Kind**: path (1.2 m wide, gravel surface)
- **Lays**: 2.0 m of route per item
- **Base Economic Value**: $4.0

## Description
Crushed gravel and edging for a smooth footpath.

Hold it and click to lay control points; the route is a smooth curve through them (docs/PATHS.md).
