# Macerator Waste Pump

**Item ID:** `waste_pump_macerator`  
**Category:** `waste`  
**Icon:** ![Macerator Waste Pump](waste_pump_macerator.png)

A grinder pump that stands inside a building between its waste outlet and the septic tank: it grinds the solids fine, so the tank fills with sludge half as fast and needs pumping out less often. It runs on the building's power; without power nothing drains through it.

Procedural model (tools/make_septic.py). See docs/SEPTIC.md.
