# Septic Distribution Box

**Item ID:** `waste_box_distribution_septic`  
**Category:** `waste`  
**Icon:** ![Septic Distribution Box](waste_box_distribution_septic.png)

A concrete distribution box, buried with its lid at the ground: it splits the liquid from a septic tank evenly between the leach fields piped to it. Pipe the tank to it, then it to each leach field, with black waste pipe.

Procedural model (tools/make_septic.py). See docs/SEPTIC.md.
