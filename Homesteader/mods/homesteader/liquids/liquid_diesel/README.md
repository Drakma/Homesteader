# Diesel Fuel (`liquid_diesel`)

![Diesel Fuel Icon](liquid_diesel.png)

## Overview
- **Category**: `liquids`
- **Item Identifier**: `liquid_diesel`
- **Weight**: 0.83 kg per litre
- **Base Economic Value**: $1.4 per litre
- **Fluid colour**: `#d9b23c`
- **Opacity**: 70%
- **Flammable**: True

## Description
On-road diesel for tractors, generators and trucks.

A liquid is not carried or placed on its own: it fills a liquid container (a bucket, can, drum or tank, see the
`liquid_container` schema) by volume, and its weight is the weight per litre times the litres held.
