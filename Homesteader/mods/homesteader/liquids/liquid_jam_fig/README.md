## Overview
- **Category**: `liquids`
- **Item Identifier**: `liquid_jam_fig`
- **Weight**: 1.3 kg per liter
- **Base Economic Value**: $6.0 per liter
- **Fluid colour**: `#6a3a3a`
- **Opacity**: 100%
- **Flammable**: False

## Description
Set fig jam: fruit, sugar and gelatin cooked down.

A liquid is not carried or placed on its own: it fills a liquid container (a bucket, can, drum or tank, see the
`liquid_container` schema) by volume, and its weight is the weight per liter times the liters held.
