# Exterior Wall Lantern

**Item ID:** `electricity_light_sconce_exterior`  
**Category:** `electricity`  
**Icon:** ![Exterior Wall Lantern](electricity_light_sconce_exterior.png)

A weatherproof lantern for the outside of a building. It lights from dusk to dawn while the building has power (a breaker box on the outside).

Mounts on a wall (exterior side). See docs/ATTACHED_ITEMS.md.
