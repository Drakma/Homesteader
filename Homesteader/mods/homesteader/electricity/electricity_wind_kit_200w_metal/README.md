# 200W Metal Wind Turbine Kit

**Item ID:** `electricity_wind_kit_200w_metal`  
**Category:** `electricity`  
**Icon:** ![200W Metal Wind Turbine Kit](electricity_wind_kit_200w_metal.png)

A kit with every part of a 200w metal wind turbine, shipped in a crate. It cannot be made from building materials: place the turbine's blueprint, then bring the kit to the site and build it in four stages (footing, mast, head, blades).
