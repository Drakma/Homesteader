# Fluorescent Light (2 Bulb)

**Item ID:** `electricity_light_fluorescent_2bulb`  
**Category:** `electricity`  
**Icon:** ![Fluorescent Light (2 Bulb)](electricity_light_fluorescent_2bulb.png)

A 2-tube fluorescent fixture: a bright white light with a wide, deep throw that sputters for a few seconds when it comes on. Mount it inside a building; it lights while the building has power (a breaker box on the outside).

Mounts on a ceiling (interior side). See docs/ATTACHED_ITEMS.md.
