# DC Breaker Box

A white wall-mounted DC breaker box with 2 breakers behind its window, for battery and solar circuits.

Procedural model (tools/make_dc_breaker_boxes.py), 466 triangles, 0.22 x 0.10 x 0.30 m. Rated 32 A: the rating is on the label under the window and stored in `category_fields.max_current_a`.
