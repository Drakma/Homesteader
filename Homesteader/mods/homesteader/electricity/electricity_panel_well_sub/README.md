# Well Pump Sub Panel

**Item ID:** `electricity_panel_well_sub`  
**Category:** `electricity`  
**Icon:** ![Well Pump Sub Panel](electricity_panel_well_sub.png)

A small weatherproof sub panel for a well pump. Fit it on a finished well (left or right click the well with it in hand), then wire it to a building's breaker box with AC wire (the cable is buried) to run the pump.
