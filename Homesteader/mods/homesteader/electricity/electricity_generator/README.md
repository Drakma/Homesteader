# Portable Generator

A wheeled open-frame gasoline generator with a recoil start, for backup power around the homestead.

Procedural model (tools/make_portable_generators.py), 1704 triangles, 0.73 x 0.58 x 0.62 m: a tube frame on two wheels and two feet, tank, engine, alternator, muffler, folding handle. The control panel, tank label, heat shield and cooling fins are pictures (tools/case_labels.py).
