# Spin-Down Sediment Filter

A reusable spin-down sediment filter with a clear bowl and a flush valve. Mount it on a wall and pipe the line through it.

Procedural model (tools/make_water_filters.py), 554 triangles, 0.18 x 0.11 x 0.30 m. A brass head on a wall plate, a clear bowl with the steel screen inside, a flush valve with a red handle. Mounts on a wall, either side; `wire_role: water_filter`. See docs/WELLS.md.
