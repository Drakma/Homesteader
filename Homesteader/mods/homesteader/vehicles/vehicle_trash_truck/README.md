# Trash Truck (`vehicle_trash_truck`)

The weekly trash truck. It comes once a week to the pickup zone, empties the wheeled trash bins standing there and charges the weekly fee.

Procedural model (tools/make_trash_assets.py), 560 triangles. Built like the cargo truck: four separate wheels Wheel_FL / FR / RL / RR (origin on the hub) and a FrontMarker empty at the nose. See docs/TRASH.md.
