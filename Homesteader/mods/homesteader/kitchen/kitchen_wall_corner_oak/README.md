# Oak Corner Wall Cabinet

An L-shaped corner wall cabinet for turning a run of wall cabinets round a corner. Mount it on the wall that has the corner on its LEFT as you face it (every inside corner is the left end of one of its two walls). Oak, butcher-block top.

Procedural model (tools/make_kitchen_assets.py, tools/kitchen_models.py), 292 triangles, 0.90 x 0.90 x 0.72 m (W x D x H). A wall item: mount it on a wall.
