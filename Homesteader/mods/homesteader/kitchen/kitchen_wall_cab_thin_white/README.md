# White Slim Wall Cabinet

A 15 cm slim wall cabinet with one narrow door, for tight spaces. Mount it on a wall. White shaker doors, marble top.

Procedural model (tools/make_kitchen_assets.py, tools/kitchen_models.py), 336 triangles, 0.15 x 0.37 x 0.72 m (W x D x H). A wall item: mount it on a wall.
