# Modern Stone Drapes

A pair of heavy floor-length drapes, tied back at the sides, hung from a rod with a valance or a ceiling track. Mount it on an inside wall: the click sets the floor. Modern styling, with a matte black rail.

Procedural model (tools/make_decor_assets.py, tools/decor_models.py), 1400 triangles, 2.26 x 0.12 x 2.49 m (W x D x H).
