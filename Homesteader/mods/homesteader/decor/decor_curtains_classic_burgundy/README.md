# Classic Burgundy Curtains

A pair of sill-length curtains on a rod, open at the sides. Mount it on an inside wall above a window: the click sets the bottom hem. Classic styling, with a brass rod.

Procedural model (tools/make_decor_assets.py, tools/decor_models.py), 1732 triangles, 1.83 x 0.11 x 1.60 m (W x D x H).
