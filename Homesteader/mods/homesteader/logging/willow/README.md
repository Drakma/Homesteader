# Willow Tree (`willow`)

![Willow Tree Icon](willow.png)

## Overview
- **Category**: `logging`
- **Item Identifier**: `willow`

## Description
A tree lifecycle growing through 4 stages (sapling -> small -> medium -> mature) over 90 days. This group is the authoritative owner of the willow scheme.

## Growth
- **Type**: `tree`
- **Species**: `willow`
- **Full age**: 90 days
- **Yield**: 3 to 4 `mat_log_willowood_uncut_long` at stage 4

| Stage | Name | Age range |
| :--- | :--- | :--- |
| 1 | sapling | 0 to 14 |
| 2 | small | 14 to 36 |
| 3 | medium | 36 to 68 |
| 4 | mature | 68 to 90 |
