# Birch Tree (`birch`)

![Birch Tree Icon](birch.png)

## Overview
- **Category**: `logging`
- **Item Identifier**: `birch`

## Description
A tree lifecycle growing through 4 stages (sapling -> small -> medium -> mature) over 100 days. This group is the authoritative owner of the birch scheme.

## Growth
- **Type**: `tree`
- **Species**: `birch`
- **Full age**: 100 days
- **Yield**: 1 to 1 `mat_log_birch_uncut_long` at stage 4
- **Planting**: year_round; seed `plantable_birch_sapling`

| Stage | Name | Age range |
| :--- | :--- | :--- |
| 1 | sapling | 0 to 15 |
| 2 | small | 15 to 40 |
| 3 | medium | 40 to 75 |
| 4 | mature | 75 to 100 |
