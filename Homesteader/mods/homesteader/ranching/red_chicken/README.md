## Description
A animal lifecycle growing through 2 stages (baby -> adult) over 730 days. This group is the authoritative owner of the red_chicken scheme.

## Growth
- **Type**: `animal`
- **Species**: `red_chicken`
- **Full age**: 730 days

| Stage | Name | Age range |
| :--- | :--- | :--- |
| 1 | baby | 0 to 90 |
| 2 | yearling | 90 to 365 |
| 3 | adult | 365 to 730 |
