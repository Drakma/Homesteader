# Classic Red Lumber Rack

Three steel arms holding a stack of boards. Mount it on a wall. Classic styling: turned legs, rolled arms, mouldings and brass.

Procedural model (tools/make_garage_assets.py, tools/garage_models.py), 156 triangles, 1.20 x 0.38 x 0.16 m (W x D x H). A wall item: mount it on a wall.
