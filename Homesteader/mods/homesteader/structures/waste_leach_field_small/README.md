# Small Leach Field

**Item ID:** `waste_leach_field_small`  
**Category:** `structures`  
**Icon:** ![Small Leach Field](waste_leach_field_small.png)

Two gravel trenches with perforated pipe, buried: the liquid from a septic tank soaks away into the ground here. Pipe it from a distribution box. It takes so much a day; more than that and the system backs up.

Procedural model (tools/make_septic.py). See docs/SEPTIC.md.
