# Septic Tank (Poly)

**Item ID:** `waste_septic_tank_poly`  
**Category:** `structures`  
**Icon:** ![Septic Tank (Poly)](waste_septic_tank_poly.png)

A ribbed poly septic tank, buried with two green risers and lids showing just above the ground for the cleanout. Pipe a building's waste outlet to it with black waste pipe (a macerator pump on the way is optional); pipe it on to a distribution box and leach fields. Solids settle and build up in it: order a pump-out in the Tank You app before it fills.

Procedural model (tools/make_septic.py). See docs/SEPTIC.md.
