# PoE Camera

A weatherproof network camera. Mount it on a wall and run a Cat6 cable to a PoE switch: the cable powers it and carries its picture.

Procedural model (tools/make_internet.py): a white bullet camera on a wall bracket. Its detail is painted (tools/net_pictures.py). 212 triangles, 0.09 x 0.26 x 0.11 m.
