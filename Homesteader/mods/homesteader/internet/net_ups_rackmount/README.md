# Rackmount UPS

A battery backup for a wall rack (two units). When the building loses power it keeps the rack, and what the rack feeds over its cables, running: two hours with the rack fully loaded, longer with less in it. It charges again when the power is back.

Procedural model (tools/make_internet.py): a two unit rack UPS: a vented front with a display. Its detail is painted (tools/net_pictures.py). 166 triangles, 0.48 x 0.32 x 0.09 m.
