# Ethernet Wall Jack

A wall plate with an RJ45 jack on each side of the wall. Mount it on a wall: a cable from outside (the dish, another building) plugs into the outside, and the gear inside is cabled to the inside. It uses no bandwidth.

Procedural model (tools/make_internet.py): an Ethernet wall plate with a sleeve through the wall. Its detail is painted (tools/net_pictures.py). 56 triangles, 0.07 x 0.27 x 0.11 m.
