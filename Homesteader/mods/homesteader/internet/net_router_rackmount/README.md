# Rackmount Router

A wired gateway router for a rack: the dish or a yagi link comes into it and its four ports go on to switches and devices. It has no Wi-Fi of its own.

Procedural model (tools/make_internet.py): a rack router: an internet port, four LAN ports. Its detail is painted (tools/net_pictures.py). 166 triangles, 0.48 x 0.22 x 0.05 m.
