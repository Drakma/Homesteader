# 16-Port PoE Switch

A rackmount switch with sixteen gigabit ports that each give 15 W of power over the cable (PoE): cameras, access points and antennas run from it with no other supply.

Procedural model (tools/make_internet.py): a sixteen port PoE switch with rack ears. Its detail is painted (tools/net_pictures.py). 166 triangles, 0.48 x 0.26 x 0.05 m.
