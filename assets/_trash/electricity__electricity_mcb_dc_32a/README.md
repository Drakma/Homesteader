# DC Circuit Breaker

A white DIN-rail DC miniature circuit breaker (MCB) that protects a battery or solar circuit, one pole.

Procedural model (tools/make_breakers.py), 200 triangles, 0.018 x 0.086 x 0.084 m. Rated 32 A (1 pole): the rating is printed on the front and stored in `category_fields.max_current_a`.
