# DC Circuit Breaker

A white DIN-rail DC miniature circuit breaker (MCB) that protects a battery or solar circuit, four poles.

Procedural model (tools/make_breakers.py), 836 triangles, 0.072 x 0.087 x 0.084 m. Rated 128 A (4 poles): the rating is printed on the front and stored in `category_fields.max_current_a`.
