# Plastic Sawhorse

A folding moulded plastic sawhorse with a tray shelf and notches in the top rail that hold a 2x4 on edge. Light and quick to set up.

Procedural model (tools/make_sawhorses.py), 724 triangles, 0.75 x 0.47 x 0.77 m. Two yellow leg frames hinged under a black notched rail, a tray shelf, rubber feet.
