# Metal Sawhorse

A folding steel sawhorse with tube legs, a channel top rail and locking stays. Carries the heaviest loads.

Procedural model (tools/make_sawhorses.py), 720 triangles, 0.95 x 0.50 x 0.77 m. Galvanized tube legs on bolted hinge brackets under a painted channel rail, folding stays, rubber feet.
