# Push Mower

A walk-behind push mower with a 53 cm cutting deck. Push it over open ground (right click the handles with an empty hand, right click again to let go) and the grass under the deck is cut into a fresh lawn with light and dark stripes that run the way you walked. It does not cut farmland, roads or water.

Procedural model (tools/make_push_mower.py), 1324 triangles, 1.12 x 0.63 x 0.98 m. `pushable`, `mower_width_m` 0.53. See docs/MOWING.md.
