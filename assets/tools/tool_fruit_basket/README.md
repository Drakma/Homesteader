# Fruit Basket (`tool_fruit_basket`)

![Fruit Basket Icon](tool_fruit_basket.png)

## Overview
- **Category**: `tools`
- **Item Identifier**: `tool_fruit_basket`
- **Max Stack Size**: 1
- **Weight**: 1.2 kg
- **Base Economic Value**: $25.0
- **Consumable**: False

## Description
A woven wicker basket for picking fruit by hand from fruiting trees. It is the harvest tool for the kit's `fruit.tools` (apple, lemon, orange):
put it in the active toolbar slot and right-click a ripe fruiting tree.
