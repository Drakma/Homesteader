# Wheeled Trash Bin (`waste_trash_bin_wheeled`)

A big wheeled trash bin with a hinged lid and a handle. It holds four full garbage bags. Push it by the handle to the pickup zone before the trash truck comes: only bins in the zone are emptied.

Procedural model (tools/make_trash_assets.py), 268 triangles. Handle and wheels at +x, like a wheelbarrow, so it is pushed the same way. See docs/TRASH.md.
