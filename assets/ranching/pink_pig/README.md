## Description
A animal lifecycle growing through 2 stages (piglet -> adult) over 730 days. This group is the authoritative owner of the pink_pig scheme.

## Growth
- **Type**: `animal`
- **Species**: `pink_pig`
- **Full age**: 730 days

| Stage | Name | Age range |
| :--- | :--- | :--- |
| 1 | piglet | 0 to 90 |
| 2 | yearling | 90 to 365 |
| 3 | adult | 365 to 730 |
