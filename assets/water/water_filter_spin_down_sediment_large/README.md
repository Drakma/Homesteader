# Large Spin-Down Sediment Filter

A 2 inch spin-down sediment filter on a steel stand: a big clear bowl, a brass head and a flush valve. It takes the sand and grit out of a well line at pump flow rates. Pipe the line through it.

Procedural model (tools/make_water_filters_large.py), 582 triangles, 0.38 x 0.25 x 0.79 m. Stands on the floor; `wire_role: water_filter`, 9000 L/h. See docs/WATER_FLOW.md.
