# Modern Stone Curtains

A pair of sill-length curtains on a rod, open at the sides. Mount it on an inside wall above a window: the click sets the bottom hem. Modern styling, with a matte black rail.

Procedural model (tools/make_decor_assets.py, tools/decor_models.py), 964 triangles, 1.78 x 0.10 x 1.59 m (W x D x H).
