# Classic Green Drapes

A pair of heavy floor-length drapes, tied back at the sides, hung from a rod with a valance or a ceiling track. Mount it on an inside wall: the click sets the floor. Classic styling, with a brass rod.

Procedural model (tools/make_decor_assets.py, tools/decor_models.py), 2436 triangles, 2.26 x 0.13 x 2.49 m (W x D x H).
