# Apple Tree (`apple`)

![Apple Tree Icon](apple.png)

## Overview
- **Category**: `logging`
- **Item Identifier**: `apple`

## Description
A tree lifecycle growing through 5 stages (sapling -> small -> medium -> mature -> fruiting) over 81 days. No fruit is visible until the final fruiting stage. This group is the authoritative owner of the apple scheme.

## Growth
- **Type**: `tree`
- **Species**: `apple`
- **Full age**: 81 days
- **Yield**: 1 to 1 `mat_log_oak_uncut_long` at stage 4

| Stage | Name | Age range |
| :--- | :--- | :--- |
| 1 | sapling | 0 to 12 |
| 2 | small | 12 to 32 |
| 3 | medium | 32 to 60 |
| 4 | mature | 60 to 80 |
| 5 | fruiting | 80 to 81 |
