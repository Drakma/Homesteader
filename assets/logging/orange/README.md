# Orange (`orange`)

![Orange Icon](orange.png)

## Overview
- **Category**: `logging`
- **Item Identifier**: `orange`

## Description
A tree lifecycle growing through 5 stages (sapling -> small -> medium -> mature -> fruiting) over 300 days. No fruit is visible until the final fruiting stage. This group is the authoritative owner of the orange scheme.

## Growth
- **Type**: `tree`
- **Species**: `orange`
- **Full age**: 300 days
- **Yield**: 1 to 1 `mat_log_oak_uncut_long` at stage 4
- **Planting**: year_round; seed `plantable_sapling_orange`

| Stage | Name | Age range |
| :--- | :--- | :--- |
| 1 | sapling | 0 to 100 |
| 2 | small | 100 to 199 |
| 3 | medium | 199 to 290 |
| 4 | mature | 290 to 299 |
| 5 | fruiting | 299 to 300 |
