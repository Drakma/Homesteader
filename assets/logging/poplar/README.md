# Poplar Tree (`poplar`)

![Poplar Tree Icon](poplar.png)

## Overview
- **Category**: `logging`
- **Item Identifier**: `poplar`

## Description
A tree lifecycle growing through 4 stages (sapling -> small -> medium -> mature) over 80 days. This group is the authoritative owner of the poplar scheme.

## Growth
- **Type**: `tree`
- **Species**: `poplar`
- **Full age**: 80 days
- **Yield**: 3 to 4 `mat_log_poplar_uncut_long` at stage 4

| Stage | Name | Age range |
| :--- | :--- | :--- |
| 1 | sapling | 0 to 12 |
| 2 | small | 12 to 32 |
| 3 | medium | 32 to 60 |
| 4 | mature | 60 to 80 |
