# Pine Tree (`pine`)

![Pine Tree Icon](pine.png)

## Overview
- **Category**: `logging`
- **Item Identifier**: `pine`

## Description
A tree lifecycle growing through 4 stages (sapling -> small -> medium -> mature) over 100 days. This group is the authoritative owner of the pine scheme.

## Growth
- **Type**: `tree`
- **Species**: `pine`
- **Full age**: 100 days
- **Yield**: 3 to 4 `mat_log_pine_uncut_long` at stage 4

| Stage | Name | Age range |
| :--- | :--- | :--- |
| 1 | sapling | 0 to 15 |
| 2 | small | 15 to 40 |
| 3 | medium | 40 to 75 |
| 4 | mature | 75 to 100 |
