# tree_mature_lemon

Lemon tree growth group - stage 4/5 (mature, pre-fruit).

- Category: logging
- Model: tree_mature_lemon.glb (Meshy text-to-3D, meshy-5, standard topology, decimated to 3000 tris, rescaled to ~3.25m height)
- Icon: rendered from the model via tools/render_icon_from_model.py
- Part of the "lemon" growth group (assets/logging/lemon/lemon.json)
