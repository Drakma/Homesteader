# Lemon (`lemon`)

![Lemon Icon](lemon.png)

## Overview
- **Category**: `logging`
- **Item Identifier**: `lemon`

## Description
A tree lifecycle growing through 5 stages (sapling -> small -> medium -> mature -> fruiting) over 300 days. No fruit is visible until the final fruiting stage. This group is the authoritative owner of the lemon scheme.

## Growth
- **Type**: `tree`
- **Species**: `lemon`
- **Full age**: 300 days
- **Yield**: 1 to 1 `mat_log_oak_uncut_long` at stage 4
- **Planting**: spring, summer; seed `plantable_sapling_lemon`

| Stage | Name | Age range |
| :--- | :--- | :--- |
| 1 | sapling | 0 to 125 |
| 2 | small | 125 to 200 |
| 3 | medium | 200 to 250 |
| 4 | mature | 250 to 299 |
| 5 | fruiting | 299 to 300 |
