# 32-Port Rackmount Switch

A managed gigabit switch with thirty-two ports, for a rack. It shares the connection of a router among many wired devices.

Procedural model (tools/make_internet.py): a thirty-two port switch with rack ears, its jacks in two rows. Its detail is painted (tools/net_pictures.py). 166 triangles, 0.48 x 0.26 x 0.05 m.
