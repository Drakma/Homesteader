# Indoor Access Point

A Wi-Fi access point for indoors. Mount it on a ceiling and cable it to a PoE port: the cable powers it. It covers the rooms round it.

Procedural model (tools/make_internet.py): a white disc access point for a ceiling, a ring light underneath. Its detail is painted (tools/net_pictures.py). 202 triangles, 0.20 x 0.20 x 0.04 m.
