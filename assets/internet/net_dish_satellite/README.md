# Satellite Dish

A flat satellite internet antenna on a kickstand. Stand it in the open with a clear view of the sky: it brings the internet to the homestead.

Procedural model (tools/make_internet.py): a flat white satellite antenna on its kickstand. Its detail is painted (tools/net_pictures.py). 136 triangles, 0.50 x 0.43 x 0.17 m.
