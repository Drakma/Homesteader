# Compact PoE Switch

A small desktop network switch with five gigabit ports that also power what is plugged into them (PoE): a camera, an access point.

Procedural model (tools/make_internet.py): a compact five port PoE switch. Its detail is painted (tools/net_pictures.py). 118 triangles, 0.16 x 0.10 x 0.03 m.
