# Concrete Mix Bag

An 20 lb bag of ready-mix concrete: add water and pour.

Model: the 20lb sand bag's model (`20lb_sand_bag`) scaled to 20 lb size (0.59 x 0.35 x 0.16 m, lying flat), recoloured orange with charcoal accents
and a CONCRETE MIX label. 4,240 triangles, texture embedded. No longer built by tools/make_building_items.py (listed in its HAND_MADE set).
