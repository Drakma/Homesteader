# Door Hardware Set

A door knob set with its latch and a pair of hinges.

Procedural model (tools/make_door_hardware.py), 2138 triangles, 0.29 x 0.21 x 0.08 m: two knobs on their roses (one keyed, one with a thumb turn), the latch and its faceplate, the strike plate, a pair of butt hinges and the screws.
