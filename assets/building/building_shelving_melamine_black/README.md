# Black Melamine Shelving Unit

A 2 m workshop shelving unit in black melamine, with four deep shelves and a back panel. Place it, then stand things on its shelves: point at the open front of a shelf and put an item down there; like things stack on each other.

Procedural model (tools/make_shelving_units.py), 484 triangles, 1.22 x 0.60 x 2.00 m. Four shelves, tops at 0.15, 0.62, 1.09, 1.56 m (`properties.deck_heights`).
