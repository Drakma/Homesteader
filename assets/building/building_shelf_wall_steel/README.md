# Steel Wall Shelf

A deep galvanized steel shelf on heavy angle brackets, for a garage or a shed. Mount it on a wall, then stand things on it: left click with the item in hand, right click the item to take it back.

Procedural model (tools/make_shelves.py), 360 triangles, 1.20 x 0.35 x 0.24 m. A wall item (`attach_surface: wall`) that is a shelf (`shelf: true`): things stand on its top face. See docs/ATTACHED_ITEMS.md.
