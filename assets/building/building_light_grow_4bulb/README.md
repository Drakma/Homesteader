# Grow Light

A hanging grow light with 4 magenta tubes under a finned black housing: a steady violet light for plants indoors. Mount it on a ceiling inside a building; it lights while the building has power (a breaker box on the outside).

Procedural model (tools/make_grow_lights.py), 608 triangles, 1.20 x 0.42 x 0.30 m, 4 tubes. Mounts on a ceiling (interior side) and hangs 0.30 m below it. See docs/ATTACHED_ITEMS.md.
