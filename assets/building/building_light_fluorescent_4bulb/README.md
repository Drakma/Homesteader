# Fluorescent Light (4 Bulb)

**Item ID:** `building_light_fluorescent_4bulb`  
**Category:** `electricity`  
**Icon:** ![Fluorescent Light (4 Bulb)](building_light_fluorescent_4bulb.png)

A 4-tube fluorescent fixture: a bright white light with a wide, deep throw that sputters for a few seconds when it comes on. Mount it inside a building; it lights while the building has power (a breaker box on the outside).

Mounts on a ceiling (interior side). See docs/ATTACHED_ITEMS.md.
