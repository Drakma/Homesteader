# Flagstone Path Kit (`path_stone`)

![Flagstone Path Kit Icon](path_stone.png)

## Overview
- **Category**: `building`
- **Item Identifier**: `path_stone`
- **Kind**: path (1.2 m wide, stone surface)
- **Lays**: 1.5 m of route per item
- **Base Economic Value**: $14.0

## Description
Flat stones laid as a smooth, curving footpath.

Hold it and click to lay control points; the route is a smooth curve through them (docs/PATHS.md).
