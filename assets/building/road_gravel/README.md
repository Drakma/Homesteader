# Gravel Road Kit (`road_gravel`)

![Gravel Road Kit Icon](road_gravel.png)

## Overview
- **Category**: `building`
- **Item Identifier**: `road_gravel`
- **Kind**: road (4.0 m wide, gravel surface)
- **Lays**: 1.5 m of route per item
- **Base Economic Value**: $20.0

## Description
Compacted road gravel for a drivable farm lane.

Hold it and click to lay control points; the route is a smooth curve through them (docs/PATHS.md).
