# Asphalt Road Kit (`road_asphalt`)

![Asphalt Road Kit Icon](road_asphalt.png)

## Overview
- **Category**: `building`
- **Item Identifier**: `road_asphalt`
- **Kind**: road (4.0 m wide, asphalt surface)
- **Lays**: 1.0 m of route per item
- **Base Economic Value**: $55.0

## Description
Asphalt paving with a centre line for a proper road.

Hold it and click to lay control points; the route is a smooth curve through them (docs/PATHS.md).
