Homesteader HUD Font License
============================

The fonts in this directory named homesteader_hud*.ttf are
derivative works of the Fira Sans typeface by Carrois Apostrophe
under the SIL Open Font License, version 1.1.

The fonts in this directory were modified from the original Fira Sans
release by extracting the Fira Sans glyph outlines and renaming the
family to "Homesteader HUD". As permitted by the SIL Open Font
License (section 1, "Definition of Modified Version"), we have:

 1. Set a different family name: "Homesteader HUD".
 2. Restated the per-weight style names (Regular, Medium, Bold,
     Italic, Bold Italic) for the new family.
 3. Left the original Fira Sans copyright notices intact in the
     resulting TTFs' name table (record IDs 0 - 11).
