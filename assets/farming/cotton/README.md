# Cotton Plant (`cotton`)

![Cotton Plant Icon](cotton.png)

## Overview
- **Category**: `farming`
- **Item Identifier**: `cotton`

## Description
A cotton lifecycle growing through 5 stages (sprout -> small -> medium -> mature -> ripe) over 150 days, with withered and dead versions. The models are procedural (built in the game), the originals are kept in assets/_originals/crops_old.

## Growth
- **Type**: `crop`
- **Species**: `cotton`
- **Full age**: 150 days
- **Yield**: 1 to 3 `ingredient_cotton` at stage 5
- **Planting**: summer; seed `seed_cotton`

| Stage | Name | Age range |
| :--- | :--- | :--- |
| 1 | sprout | 0 to 16 |
| 2 | small | 16 to 50 |
| 3 | medium | 50 to 90 |
| 4 | mature | 90 to 124 |
| 5 | ripe | 124 to 150 |
