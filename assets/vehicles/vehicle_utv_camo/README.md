# Camo Side by Side UTV (`vehicle_utv_camo`)

![Icon](vehicle_utv_camo.png)

## Overview
- **Category**: `vehicles`
- **Item Identifier**: `vehicle_utv_camo`

## Description
A camouflage side by side utility vehicle: two seats, a roll cage and a small cargo bed. Goes where a truck cannot.

Built in code (`tools/make_pickups_utv.py`), low poly. The four wheels are separate objects named `Wheel_FL`, `Wheel_FR`, `Wheel_RL`, `Wheel_RR`
with their origin on the hub; an empty named `FrontMarker` sits at the nose.
