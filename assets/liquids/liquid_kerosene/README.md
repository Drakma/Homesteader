## Overview
- **Category**: `liquids`
- **Item Identifier**: `liquid_kerosene`
- **Weight**: 0.81 kg per litre
- **Base Economic Value**: $1.6 per litre
- **Fluid colour**: `#e7dfae`
- **Opacity**: 60%
- **Flammable**: True

## Description
Clear kerosene for lamps and heaters.

A liquid is not carried or placed on its own: it fills a liquid container (a bucket, can, drum or tank, see the
`liquid_container` schema) by volume, and its weight is the weight per litre times the litres held.
