# Maple Sap (`liquid_maple_sap`)

![Maple Sap Icon](liquid_maple_sap.png)

## Overview
- **Category**: `liquids`
- **Item Identifier**: `liquid_maple_sap`
- **Weight**: 1.01 kg per liter
- **Base Economic Value**: $0.5 per liter
- **Fluid colour**: `#e6eee2`
- **Opacity**: 30%
- **Flammable**: False

## Description
Thin, barely sweet sap tapped from maple trees.

A liquid is not carried or placed on its own: it fills a liquid container (a bucket, can, drum or tank, see the
`liquid_container` schema) by volume, and its weight is the weight per liter times the liters held.
