# Liquid Propane (`liquid_propane`)

![Liquid Propane Icon](liquid_propane.png)

## Overview
- **Category**: `liquids`
- **Item Identifier**: `liquid_propane`
- **Weight**: 0.51 kg per litre
- **Base Economic Value**: $0.8 per litre
- **Fluid colour**: `#cfe8f4`
- **Opacity**: 45%
- **Flammable**: True

## Description
Propane stored as a liquid under pressure.

A liquid is not carried or placed on its own: it fills a liquid container (a bucket, can, drum or tank, see the
`liquid_container` schema) by volume, and its weight is the weight per litre times the litres held.
