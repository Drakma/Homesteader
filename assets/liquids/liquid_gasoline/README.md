# Gasoline (`liquid_gasoline`)

![Gasoline Icon](liquid_gasoline.png)

## Overview
- **Category**: `liquids`
- **Item Identifier**: `liquid_gasoline`
- **Weight**: 0.74 kg per liter
- **Base Economic Value**: $1.2 per liter
- **Fluid colour**: `#e6d36a`
- **Opacity**: 65%
- **Flammable**: True

## Description
Unleaded gasoline for small engines and mowers.

A liquid is not carried or placed on its own: it fills a liquid container (a bucket, can, drum or tank, see the
`liquid_container` schema) by volume, and its weight is the weight per liter times the liters held.
