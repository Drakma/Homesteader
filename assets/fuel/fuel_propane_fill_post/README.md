# Propane Fill Post

A post set in the ground with a fill valve, a gauge and a yellow hose, for filling portable propane tanks. Pipe it to a big propane tank with propane pipe and a pipe wrench, then right click it with a portable tank in hand to fill that tank.

Procedural model (tools/make_propane_line.py), 626 triangles, 0.34 x 0.34 x 1.16 m. `wire_role: propane_filler`. See docs/WIRING.md.
