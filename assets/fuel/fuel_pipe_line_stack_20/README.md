# Fuel Line Stack (`fuel_pipe_line_stack_20`)

20 lengths of fuel line strapped together, 60 m in all: gasoline and diesel line for a long run to a pump.

Procedural model (tools/make_fuel_line_stacks.py): 20 lengths in 5 rows, strapped, 2676 triangles. `wire_kind: fuel`, 60 m a stack. See docs/WIRING.md.
