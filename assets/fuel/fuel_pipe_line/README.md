# Fuel Line (`fuel_pipe_line`)

A 3 m length of black coated steel pipe for gasoline or diesel. With a pipe wrench in hand, right click a bulk fuel tank and then a fuel pump to lay it (or tank to tank): it runs underground outside.

Procedural model (tools/make_fuel_line.py), 152 triangles. `wire_kind: fuel`, 3 m a length. See docs/WIRING.md.
