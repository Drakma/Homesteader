# Pendant Ceiling Light

**Item ID:** `electricity_light_ceiling_pendant`  
**Category:** `electricity`  
**Icon:** ![Pendant Ceiling Light](electricity_light_ceiling_pendant.png)

A shaded light that hangs from the ceiling on a cord. Mount it inside a building; it lights while the building has power (a breaker box on the outside).

Mounts on a ceiling (interior side). See docs/ATTACHED_ITEMS.md.
