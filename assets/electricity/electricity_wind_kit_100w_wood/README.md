# 100W Wooden Wind Turbine Kit

**Item ID:** `electricity_wind_kit_100w_wood`  
**Category:** `electricity`  
**Icon:** ![100W Wooden Wind Turbine Kit](electricity_wind_kit_100w_wood.png)

A kit with every part of a 100w wooden wind turbine, shipped in a crate. It cannot be made from building materials: place the turbine's blueprint, then bring the kit to the site and build it in four stages (footing, mast, head, blades).
