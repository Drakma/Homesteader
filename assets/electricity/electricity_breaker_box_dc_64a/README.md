# DC Breaker Box

A white wall-mounted DC breaker box with 4 breakers behind its window, for battery and solar circuits.

Procedural model (tools/make_dc_breaker_boxes.py), 606 triangles, 0.32 x 0.11 x 0.34 m. Rated 64 A: the rating is on the label under the window and stored in `category_fields.max_current_a`.
