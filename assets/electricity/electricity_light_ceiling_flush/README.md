# Flush Ceiling Light

**Item ID:** `electricity_light_ceiling_flush`  
**Category:** `electricity`  
**Icon:** ![Flush Ceiling Light](electricity_light_ceiling_flush.png)

A round dome light that sits flat on the ceiling. Mount it inside a building; it lights while the building has power (a breaker box on the outside).

Mounts on a ceiling (interior side). See docs/ATTACHED_ITEMS.md.
