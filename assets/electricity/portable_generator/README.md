# Frame Generator

A large wheeled open-frame gasoline generator with a recoil start, for running heavy loads.

Procedural model (tools/make_portable_generators.py), 1704 triangles, 0.86 x 0.66 x 0.71 m: a tube frame on two wheels and two feet, tank, engine, alternator, muffler, folding handle. The control panel, tank label, heat shield and cooling fins are pictures (tools/case_labels.py).
