# Fluorescent Light (8 Bulb)

**Item ID:** `electricity_light_fluorescent_8bulb`  
**Category:** `electricity`  
**Icon:** ![Fluorescent Light (8 Bulb)](electricity_light_fluorescent_8bulb.png)

A 8-tube fluorescent fixture: a bright white light with a wide, deep throw that sputters for a few seconds when it comes on. Mount it inside a building; it lights while the building has power (a breaker box on the outside).

Mounts on a ceiling (interior side). See docs/ATTACHED_ITEMS.md.
