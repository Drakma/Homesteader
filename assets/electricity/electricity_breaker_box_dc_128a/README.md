# DC Breaker Box

A white wall-mounted DC breaker box with 8 breakers behind its window, for battery and solar circuits.

Procedural model (tools/make_dc_breaker_boxes.py), 818 triangles, 0.46 x 0.12 x 0.40 m. Rated 128 A: the rating is on the label under the window and stored in `category_fields.max_current_a`.
