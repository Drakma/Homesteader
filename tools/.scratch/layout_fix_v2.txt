fix(Assets): make icon tiles + wells readable - 2px borders, 28px size, fills

Per "all empty single pixel squares" feedback: the previous
USS had 1-px borders + tiny sizes (18-22px) on icon-tile, well,
and tool-slot elements, which render as a single device-pixel
per side at PanelSettings ConstantPixelSize scale (0.62x).
Bumping everything to 2px borders + 28-40px sizes + slight tint
fills makes each element visibly distinct from the background.

HudState.cs (FormatResourceAmount):
  - Was producing '120.5 + L' (literal space-plus-space-u-n-i-t
    semicolon) instead of '120.5 L'. The C# source had a broken
    string literal concat at the non-k line: 'return amount.ToString("0.##") + " + unit;'
    with no closing quote in the second literal. The fix rebuilds
    it to the correct 'return amount.ToString("0.##") + " + unit;'
    (a single-space literal before unit). Duplicate method bodies
    introduced by the rolling fix-up were also deduped. Final brace
    count: 47/47.

HudUIBuilder.cs (Awake):
  - Added a guarded null check for doc.rootVisualElement. The HUD
    builder's Awake was throwing NullReferenceException when
    HudSceneBootstrap.ApplyKitOverlayFlag triggered a SerializedObject
    build pipeline while Awake was running. The NRE was on line 54
    (root.Clear()). Defensive null guard returns without disturbing
    the load order.
